# Data attribution

The Turkish province and district names and district center coordinates in `src/lib/turkiye-districts.ts` are adapted from [Open Admin Data — Turkey Administrative Divisions](https://github.com/open-admin-data/turkey-administrative-divisions), licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

The app keeps only district name, parent province name, and latitude/longitude. Attribution is also shown in the weather card. Dataset snapshot downloaded 2026-11-13.
